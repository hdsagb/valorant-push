# 无畏契约商店推送 · 个人版

每天自动把**国服每日商店**和**王国商店**推送到你的邮箱或企业微信。

纯本地运行，**不需要公网 IP、不需要域名、不需要服务器**：程序自带一个只监听 `127.0.0.1` 的设置向导，扫码登录、填写配置、测试推送都在本机完成。

## 功能

- **两个商店**：每日商店 + 王国商店，可自由勾选
- **两种登录**：手机 QQ 扫码 / 微信扫码，凭证只保存在本机
- **多账号**：最多绑定 10 个账号，可随时改名、解绑；推送时合并成一条消息，按账号名分区
- **两条通道**：SMTP 邮件、企业微信自建应用，二选一
- **自动回退**：企业微信返回 60020（可信 IP 不匹配）时自动改用邮件；主渠道没配好也会自动切换
- **图文推送**：2×2 商品卡片长图 + 文字摘要
- **定时补推**：每天固定时间推送；关机错过时间，下次开机后自动补推当天内容
- **开箱即用**：Windows 单文件 exe + 系统托盘 + 开机自启

## 快速开始

1. **运行程序**：双击 `ValorantPushPersonal.exe`。首次启动会自动打开设置页面（`http://127.0.0.1:8787`），托盘出现红色 V 图标。
2. **扫码登录**：在第 1 张卡片选择「QQ 扫码」或「微信扫码」，点「生成登录二维码」，用手机扫码确认。登录成功后会给账号起个名字（如「大号」「小号」），在「已绑定账号」卡片可重复扫码绑定更多账号（最多 10 个），也可随时改名或解绑。
3. **配置推送**：在第 3 张卡片选择渠道并填写参数，点「发送测试消息」确认能收到，然后点底部「保存全部设置」。
4. 在第 4 张卡片开启「每日定时推送」和「开机自动启动」，完成。

之后程序常驻托盘，到点自动推送。想立刻看效果，可在第 5 张卡片点「现在推送一次」。

> 设置页面只绑定本机地址，并校验 Host 头，局域网内其他设备无法访问。

## 邮件配置

以 QQ 邮箱为例：

1. 登录 QQ 邮箱网页版 → 设置 → 账号 → 开启「POP3/SMTP 服务」。
2. 按提示生成**授权码**（不是 QQ 密码）。
3. 在向导中填写：发件邮箱、授权码、收件邮箱（留空则发给自己）、SMTP 服务器、端口、加密方式。

常见服务商参数：

| 邮箱 | SMTP 服务器 | 端口 | 加密 |
| --- | --- | --- | --- |
| QQ / Foxmail | `smtp.qq.com` | 465 | SSL |
| 163 | `smtp.163.com` | 465 | SSL |
| 126 | `smtp.126.com` | 465 | SSL |
| Gmail | `smtp.gmail.com` | 587 | STARTTLS |
| Outlook / Hotmail | `smtp.office365.com` | 587 | STARTTLS |
| 新浪 | `smtp.sina.com` | 465 | SSL |

## 企业微信配置

1. 企业微信管理后台 → 应用管理 → 创建自建应用，记下 **AgentId** 和 **Secret**；「我的企业」页面可查看 **企业 ID（corpid）**。
2. 在应用详情里把本机出口 IP 加入「企业可信 IP」。设置页会自动检测当前 IP 并打码显示，点「复制」即可拿到完整地址；IP 变化后可点「重新检测」。
3. 向导中填写 corpid、AgentId、Secret、接收人 userid（多个用 `|` 分隔，`@all` 表示全员）。

> 家用宽带公网 IP 会变化，一旦和企业后台记录不一致，接口会返回 **60020**。此时程序会自动改用邮件推送（需同时配置好邮件），并在页面提示原因。

## 数据与隐私

所有数据都在程序目录的 `data/` 下：

```
data/
├── settings.json     # 推送配置（含邮箱授权码 / 企业微信 Secret）
├── accounts.json     # 已绑定的账号与登录凭证（最多 10 个）
├── state.json        # 上次推送时间、失败原因
├── out/              # 生成过的商店图片
├── temp/             # 二维码等临时文件
└── app.log           # 运行日志
```

- 不会上传到任何第三方服务器；请求只发往腾讯商店接口、你配置的 SMTP 服务器或企业微信 API。
- 分享程序或反馈问题时，**不要打包 `data/` 目录**。
- 设置页面里已保存的密码不会回显，输入框留空表示保持原值。

## 常见问题

**扫码后一直显示等待？**
二维码有效期约几分钟，过期后重新点「生成登录二维码」即可；扫码后还需要在手机上点确认。

**测试消息成功，但定时没收到？**
检查托盘程序是否在运行、第 4 张卡片的定时开关和时间是否正确；查看 `data/app.log` 的报错。邮件可能进了垃圾箱。

**提示登录已失效？**
凭证过期后会在「已绑定账号」里标红，并尝试发一条提醒。用同一账号重新扫码会自动更新凭证；部分账号失效时推送会跳过它们，其余账号照常推送，全部失效才会暂停定时任务。

**绑定的账号太多？**
在「已绑定账号」卡片点「解绑」即可移除（最多同时绑定 10 个）。解绑只删除本机凭证，不会影响账号本身。

**关了电脑错过推送时间？**
不会漏：程序启动后会检查当天是否已推送，未推送则立即补推。

**端口 8787 被占用？**
程序会自动顺延到 8788–8807。实际地址以托盘菜单或启动日志为准。

**想换电脑 / 重装？**
整个程序目录拷走即可；`data/` 里包含凭证和配置。不想带走就只拷 exe，重新扫码配置。

## 本地运行（开发者）

需要 Python 3.10+（Windows）。

```bash
pip install -r requirements.txt
python -m app                # 托盘 + 设置面板
python -m app --headless     # 只跑后台，便于调试
python -m app --push-now     # 立即推送一次后退出
python -m app --debug        # 输出调试日志
python -m app --version
```

可用环境变量 `VAL_PUSH_DATA_DIR` 指定其他数据目录，便于测试时隔离数据。

跑单元测试（账号管理相关）：

```bash
pip install pytest
python -m pytest tests -q
```

测试会把数据目录指向临时目录，不会读写真实的 `data/`。

## 打包

```bash
pip install pyinstaller
pyinstaller ValorantPushPersonal.spec
```

产物为 `dist/ValorantPushPersonal.exe`（单文件、无控制台窗口）。

仓库自带 GitHub Actions：推送 `v*` 标签（例如 `v1.0.0`）会自动在 Windows Runner 上构建并创建 Release，也可以在 Actions 页面手动触发。

## 目录结构

```
app/
├── __main__.py      # 入口与命令行参数
├── web.py           # 本地设置向导（aiohttp，仅 127.0.0.1）
├── pipeline.py      # 取商店 → 渲染 → 发送
├── scheduler.py     # 定时检查与补推
├── cn_client.py     # 国服商店接口封装
├── login.py         # QQ / 微信扫码登录会话
├── accounts.py      # 多账号凭证存储（改名 / 解绑 / 上限 10）
├── render.py        # 2×2 卡片长图
├── config.py        # 配置与状态读写
├── channels/        # 邮件、企业微信
├── tray.py          # 系统托盘
├── autostart.py     # 开机自启（注册表）
└── vendor/          # 复用的扫码登录实现
```
