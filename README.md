# 无畏契约商店推送 · 个人版

每天自动把**国服每日商店**和**王国商店**推送到你的邮箱或企业微信。

纯本地运行，**不需要公网 IP、不需要域名、不需要服务器**：程序自带一个只监听 `127.0.0.1` 的设置向导，扫码登录、填写配置、测试推送都在本机完成。

## 功能

- **两个商店**：每日商店 + 王国商店，可自由勾选
- **两种登录**：手机 QQ 扫码 / 微信扫码，凭证只保存在本机
- **多账号**：最多绑定 10 个账号，可随时改名、解绑；推送时合并成一条消息，按账号名分区
- **两条通道**：SMTP 邮件、企业微信自建应用，二选一
- **自动回退**：企业微信返回 60020（可信 IP 不匹配）时自动改用邮件；主渠道没配好也会自动切换
- **图文推送**：2×2 商品卡片长图 + 文字摘要
- **定时补推**：每天固定时间推送；关机错过时间，下次开机后自动补推当天内容
- **开箱即用**：Windows 单文件 exe + 系统托盘 + 开机自启

## 快速开始

1. **运行程序**：双击 `ValorantPushPersonal.exe`。首次启动会自动打开设置页面（`http://127.0.0.1:8787`），托盘出现红色 V 图标。
2. **扫码登录**：在第 1 张卡片选择「QQ 扫码」或「微信扫码」，点「生成登录二维码」，用手机扫码确认。登录成功后会给账号起个名字（如「大号」「小号」），在「已绑定账号」卡片可重复扫码绑定更多账号（最多 10 个），也可随时改名或解绑。
3. **配置推送**：在第 3 张卡片选择渠道并填写参数，点「发送测试消息」确认能收到，然后点底部「保存全部设置」。
4. 在第 4 张卡片开启「每日定时推送」和「开机自动启动」，完成。

> **Windows SmartScreen 提示**：exe 没有代码签名，首次运行时可能弹出「Windows 已保护你的电脑」。确认文件下载自本仓库 Release 后，点「更多信息」→「仍要运行」即可。如果来源不明，请不要继续运行。部分杀毒软件也可能对未签名程序误报，可自行添加信任或改用源码运行。

之后程序常驻托盘，到点自动推送。想立刻看效果，可在第 5 张卡片点「现在推送一次」。

> 设置页面只绑定 `127.0.0.1`，并校验 Host、Origin、Sec-Fetch-Site；写操作还要求页面携带随机令牌和自定义请求头，其他网站无法借用你的浏览器调用本地接口。

## 邮件配置

以 QQ 邮箱为例：

1. 登录 QQ 邮箱网页版 → 设置 → 账号 → 开启「POP3/SMTP 服务」。
2. 按提示生成**授权码**（不是 QQ 密码）。
3. 在向导中填写：发件邮箱、授权码、收件邮箱（留空则发给自己）、SMTP 服务器、端口、加密方式。

程序只支持 **SSL** 与 **STARTTLS** 两种加密方式，不提供「不加密 SMTP」：服务器不支持 TLS 时会拒绝发送，避免授权码被明文传输。

常见服务商参数：

| 邮箱 | SMTP 服务器 | 端口 | 加密 |
| --- | --- | --- | --- |
| QQ / Foxmail | `smtp.qq.com` | 465 | SSL |
| 163 | `smtp.163.com` | 465 | SSL |
| 126 | `smtp.126.com` | 465 | SSL |
| Gmail | `smtp.gmail.com` | 587 | STARTTLS |
| Outlook / Hotmail | `smtp.office365.com` | 587 | STARTTLS |
| 新浪 | `smtp.sina.com` | 465 | SSL |

## 企业微信配置

企业微信需要先有一个「企业」（组织），再用其中的自建应用给成员发消息。个人也可以注册一个只给自己用的企业，无需完成企业认证即可创建自建应用。

### 1. 准备企业

- 没有企业：打开 [work.weixin.qq.com](https://work.weixin.qq.com/) → 立即注册，按提示填写企业名称、行业、规模，用微信扫码创建。成员只有自己也可以正常使用。
- 已有企业：直接用管理员账号登录 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame)。

### 2. 获取企业 ID（corpid）

管理后台 → **我的企业** → **企业信息** → 页面底部 **企业 ID**，形如 `ww1234567890abcdef`。

### 3. 创建自建应用

1. 管理后台 → **应用管理** → **应用** → **自建** → **创建应用**。
2. 填写应用名称（如「商店推送」）、上传头像，**可见范围**勾选需要收到推送的成员或部门。
   - 可见范围很重要：接收人不在范围内时，发送会返回 `81013`。
   - 之后也可以在「应用管理 → 你的应用 → 可见范围」里修改。
3. 创建完成后进入应用详情页：
   - **AgentId**：详情页顶部直接显示，是一串数字，如 `1000002`。
   - **Secret**：点「查看」，按提示在企业微信客户端里确认后显示。Secret 等同于应用密码，不要截图或提交到公开仓库；遗失可点「重置」，重置后需要回到设置页重新填写。

### 4. 配置企业可信 IP

自建应用默认只允许白名单内的 IP 调用接口：

1. 应用详情页 → **开发者接口** → **企业可信 IP** → **配置**。
2. 填入本机当前的**出口公网 IP**（不是内网 IP，如 `192.168.x.x` 无效），可一次填多个。
3. 不知道出口 IP 时，打开设置页 → 第 3 张卡片选择「企业微信」，点「检测 IP」：
   - 页面只展示打码后的地址（如 `223.167.***.***`），保护隐私；
   - 点「复制」即可把完整 IP 复制到剪贴板，粘贴到企业后台；
   - IP 变了再点一次「检测 IP」刷新。

> 「检测 IP」会依次请求 `myip.ipip.net`、`icanhazip.com`、`ifconfig.me`、`api.ipify.org` 四个公共服务，把本机公网 IP 返回给页面。这是本程序唯一的第三方 IP 查询，且**只在你点击按钮时发生**；不想使用可以自行在浏览器搜索「IP」后手动粘贴。

> 出口 IP 会受这些因素影响：宽带重播/重启光猫、切换 Wi-Fi 或运营商、开启 VPN 或代理、公司网络统一出口。填错了就会返回 `60020`。

### 5. 获取接收人 userid

1. 管理后台 → **通讯录** → 点击要接收消息的成员。
2. 在成员详情里找到 **账号**（即 userid），形如 `ZhangSan`，注意不是姓名或手机号。
3. 多个接收人用 `|` 分隔，例如 `ZhangSan|LiSi`；填 `@all` 表示应用可见范围内的所有人。

### 6. 在设置页填写并测试

1. 打开 http://127.0.0.1:8787 → 第 3 张卡片选择「企业微信」。
2. 依次填写 **企业 ID**、**AgentId**、**Secret**、**接收人**。
3. 点「发送测试消息」，企业微信里能收到即配置正确。
4. 点页面底部「保存全部设置」。

推送内容为两条消息：先发一张商店长图，再发文字摘要（多账号时按账号名分区，文字上限 2000 字）。

### 常见错误码

| errcode | 含义 | 处理方式 |
| --- | --- | --- |
| 60020 | 本机出口 IP 不在「企业可信 IP」白名单 | 重新检测 IP，更新后台白名单 |
| 81013 | 接收人无效或不在应用可见范围 | 检查 userid 拼写、把成员加入应用可见范围 |
| 40013 | corpid 不正确 | 核对「我的企业 → 企业信息」里的企业 ID |
| 40014 / 40001 | Secret 不正确或已失效 | 重新查看或重置 Secret 后填写 |
| 40056 | AgentId 不合法 | 核对应用详情页的 AgentId（纯数字） |

> 家用宽带公网 IP 会变化，一旦和企业后台记录不一致，接口会返回 **60020**。此时程序会自动改用邮件推送（需同时配置好邮件），并在页面提示原因；更新白名单或重新检测 IP 后即可恢复。

## 迁移到服务器版（导出凭证包）

如需电脑关机后也能准时推送，可部署服务器版（见仓库 `server/` 子项目文档），并把账号凭证迁移过去：

1. 在「已绑定账号」卡片点「导出凭证包」，设置一个口令（至少 8 位），得到 `valorant-push-credentials-YYYYMMDD.vpcred`；
2. 把该文件安全地传到服务器（如 `scp`），在服务器上执行 `python -m push_server --import-credentials <文件>` 并输入同一口令；
3. 凭证包内只有游戏账号登录凭证；邮箱授权码、企业微信 Secret 需在服务器版管理界面重新填写；
4. **导入完成后请删除本地导出文件**；同一账号凭证只在一端启用推送——导入服务器版后，请在个人版停止这些账号的定时推送（账号风险控制要求，详见《服务器版开发规划报告》R6）。

## 数据与隐私

所有数据都在程序目录的 `data/` 下：

```
data/
├── settings.json     # 推送配置（邮箱授权码 / 企业微信 Secret 已加密）
├── accounts.json     # 已绑定的账号与登录凭证（已加密）
├── state.json        # 上次推送时间、失败原因
├── out/              # 生成过的商店图片
├── temp/             # 二维码等临时文件
└── app.log           # 运行日志（邮箱、账号 ID 已打码）
```

- 敏感字段（邮箱授权码、企业微信 Secret、账号 token / openid）写盘前用 **Windows DPAPI** 加密，密钥绑定当前 Windows 用户：文件被拷到别的电脑、别的用户或其他机器读取时无法解密。
- 启动时会用 `icacls` 把 `data/` 权限收紧到仅当前 Windows 用户。
- 程序没有遥测、统计或自动更新。网络请求只发往：腾讯商店 / 登录接口、你配置的 SMTP 服务器、企业微信 API，以及你**主动点击「检测 IP」**时的 IP 查询服务（见上文）。
- 运行日志只记录打码后的邮箱（`a***@qq.com`）与账号 ID（`***1234`）。
- 分享程序或反馈问题时，**不要打包 `data/` 目录**；日志中仍可能包含推送时间、商品名称等运行信息。
- 设置页面里已保存的密码不会回显，输入框留空表示保持原值。

## 常见问题

**扫码后一直显示等待？**
二维码有效期约几分钟，过期后重新点「生成登录二维码」即可；扫码后还需要在手机上点确认。

**测试消息成功，但定时没收到？**
检查托盘程序是否在运行、第 4 张卡片的定时开关和时间是否正确；查看 `data/app.log` 的报错。邮件可能进了垃圾箱。

**提示登录已失效？**
凭证过期后会在「已绑定账号」里标红，并尝试发一条提醒。用同一账号重新扫码会自动更新凭证；部分账号失效时推送会跳过它们，其余账号照常推送，全部失效才会暂停定时任务。

**绑定的账号太多？**
在「已绑定账号」卡片点「解绑」即可移除（最多同时绑定 10 个）。解绑只删除本机凭证，不会影响账号本身。

**关了电脑错过推送时间？**
不会漏：程序启动后会检查当天是否已推送，未推送则立即补推。

**端口 8787 被占用？**
程序会自动顺延到 8788–8807。实际地址以托盘菜单或启动日志为准。

**想换电脑 / 重装？**
`data/` 里的凭证用当前 Windows 用户的 DPAPI 密钥加密，换电脑或换用户后无法解密。把程序（exe）拷过去，重新扫码登录并重新填写邮箱授权码 / 企业微信 Secret 即可；旧电脑上的 `data/` 建议直接删除。

## 本地运行（开发者）

需要 Python 3.10+（Windows）。

```bash
pip install -r requirements.txt
python -m app                # 托盘 + 设置面板
python -m app --headless     # 只跑后台，便于调试
python -m app --push-now     # 立即推送一次后退出
python -m app --debug        # 输出调试日志
python -m app --version
```

可用环境变量 `VAL_PUSH_DATA_DIR` 指定其他数据目录，便于测试时隔离数据。

跑单元测试（账号管理相关）：

```bash
pip install pytest
python -m pytest tests -q
```

测试会把数据目录指向临时目录，不会读写真实的 `data/`。

pip install pyinstaller

> exe 未做代码签名，Windows SmartScreen 可能提示「未知发布者」。如果你不放心，可以按上面的步骤从源码自行打包。

## 目录结构

```
app/
├── __main__.py      # 入口与命令行参数
├── web.py           # 本地设置向导（aiohttp，仅 127.0.0.1）
├── pipeline.py      # 取商店 → 渲染 → 发送
├── scheduler.py     # 定时检查与补推
├── cn_client.py     # 国服商店接口封装
├── login.py         # QQ / 微信扫码登录会话
├── accounts.py      # 多账号凭证存储（改名 / 解绑 / 上限 10）
├── render.py        # 2×2 卡片长图
├── config.py        # 配置与状态读写
├── protect.py       # 敏感字段加解密（DPAPI）与日志脱敏
├── channels/        # 邮件、企业微信
├── tray.py          # 系统托盘
├── autostart.py     # 开机自启（注册表）
└── vendor/          # 复用的扫码登录实现
```
